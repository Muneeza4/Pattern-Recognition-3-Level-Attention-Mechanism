# Pattern Recognition — 3-Level Attention Mechanism

Implemented self-attention from scratch using NumPy on CoGAge HAR sensor dataset.

## Levels
- Level 1: Softmax(X·Xᵀ)·X
- Level 2: Linear Projection + Positional Encoding + Attention
- Level 3: Scaled Dot-Product Q-K-V Attention

## Dataset
CoGAge HAR | 9 sensors | 27 features | 500 timesteps

## Tech Stack
Python · NumPy · Pandas · Matplotlib · Seaborn · Scikit-learn
